# 快讯阅读页设计调整（2026-10-25）

## 交付范围

按用户圈选，移除快讯顶部标题、“最新快讯”文字、完整日期条、顶部横线、左侧工具栏竖线，以及快讯模式右上角的全屏和展开图表按钮。以 X 的简洁信息流为设计参考，使用黑白标题、较深的正文、弱化的时间信息和紧凑操作区，不使用 X 标识。

快讯改为居中单列阅读布局，取消红色标题、时间轴红点和虚线。条目通过留白区分，悬停时显示轻微底色。交易对使用圆角标签，涨跌颜色只用于涨跌数字与投票状态。较长正文默认显示五行，可展开全文；分享图片仍包含完整正文。

日历入口放到内容区的日期按钮，旁边刷新图标返回最新。日历使用顶层弹出层，位置限制在窗口内；浅色、深色主题及窄面板均适配。分享弹窗和海报同步调整为中性色、柔和圆角与无分隔线布局，所有品牌继续显示 Haolo。

修改集中在 `src/renderer/market-news.ts` 和 `src/renderer/market-news.css`。K 线 DOM 和画布保留挂载，返回 K 线后恢复图表控件。右侧会话区域不在本次修改范围。客服知识目录的四种语言说明和运行时契约已同步生成。

## 本地验证

使用 `scripts/market-news-visual-qa.mjs` 在独立、隐藏的 Electron 测试窗口内验证，复用此前记录的真实新闻响应。网络、投票、剪贴板及外部分享动作使用测试适配器，本轮没有向生产投票或发送分享内容。

- 11 组交互检查通过：移除指定元素、全文展开/收起、投票/取消/切换/失败回退、Haolo 品牌、分享图片与链接、日期筛选、分页、交易对返回 K 线、四种语言和深浅主题、错误重试、生命周期清理。
- 24 张截图覆盖标准面板、窄面板、日历、分享、四种语言及深浅主题；未发现横向溢出，日历在视口范围内。
- Chromium 字体检查确认中文正文使用 Microsoft YaHei。
- `pnpm --dir youle_desktop run typecheck` 和 `pnpm --dir youle_desktop run build` 均通过；Vite 提示现有主资源包体积较大，不影响构建完成。
- 输出记录位于 `output/flash-news-redesign-20261025/visual-report.json`，标准面板截图为同目录 `08-standard-pane-light.png`。

本次为客户端本地开发修改，不涉及后端接口变更、生产部署、版本号调整或安装包发布。

## 时间与操作区精简（2026-10-25）

根据用户最新圈选，移除每条快讯标题上方的“Haolo · 时间”行。日期和刷新入口独立放在日期分组右上方，不再为每条资讯保留空白元信息行。底部利好／利空左对齐，分享和发布时间右对齐，时间紧随分享；详情入口保留在分享左侧。同步缩小标题、正文和条目间距，窄面板允许操作分组换行，分享与时间始终保持一组。

类型检查、本地 Vite 构建以及现有 11 组快讯交互检查通过；复核标准面板、窄面板与深色主题截图，时间与分享排列正常。24 张验证截图及报告保存于 `output/flash-news-compact-20261025/`，没有覆盖上一轮证据。本次仅调整客户端阅读布局，业务接口、页面入口及客服动作协议不变。

## 整卡打开新闻中心（2026-10-25）

移除分享左侧的详情图标，整张卡片的标题、正文与空白处可打开官网新闻中心的对应快讯文章。标题使用真实链接，支持 Tab 与 Enter；选中文字不触发跳转，投票、分享、展开全文和交易对按钮各自独立。分享链接和海报二维码同步使用 `/api/news/read/flash-{ID}`。

类型检查、本地构建及 12 组交互验证通过；四语双主题 24 张截图与报告在 `output/flash-news-center-20261025/`。客服知识候选已同步。需配套官网与后端发布后新网址才在线生效；本次没有发布生产或客户端安装包。完整跨仓实现说明见官网规范仓库 `docs/news-flash-center-20261025.zh-CN.md`。
