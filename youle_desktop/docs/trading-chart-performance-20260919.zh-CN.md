# K 线画布拖动与缩放性能优化

2026-09-19，本地源码与模拟行情验收。

## 原因与修改

原生时间轴回调、导航手势、价格布局稳定帧和 VPVR 滚轮跟踪分别重绘图层。主图一帧最多重绘 4 次，并通过全局控制器列表重绘未操作的分屏。绘图层即使没有订单或文字避让需求，也会遍历全部历史 K 线；每次刷新还会销毁重建相同 SVG 内容和工具栏图标。

- 导航模块统一处理视口、拖动、缩放及布局稳定帧。绘制期间保留帧占位，防止原生惰性布局产生的新回调再开一条绘制链。
- 主图视口变化仅重绘本图及其指标窗格。共享设置、主题等需要更新所有分屏的操作仍保留原行为。
- 订单标签和文字布局按需计算 K 线避让区域，并在一次重绘内共用；计算只遍历可见范围及两侧 12px 容差。单测对比完整遍历，覆盖 10000 根历史、不同柱宽和越界视口，结果一致。
- SVG 内容没有变化时保留原节点；工具栏缓存按 DOM 元素共享，切换图表不会复用错误状态。更新内容、清空和主题变化仍正常替换。
- 连续滚轮使用相同缩放锚点时，跳过重复的图表配置写入。未新增 UI 颜色。

## 对照实测

同机、相同 Electron 隐藏窗口、关闭硬件加速的模拟行情测试；两种主题结果一致。表中帧耗时为 P95，反映较慢的帧，不代表所有设备或真实行情负载的帧率保证。

| 主图场景 | 优化前 P95 | 优化后 P95 | 单帧图层重绘 |
|---|---:|---:|---:|
| 5000 根 K 线，上下左右拖动 | 50.0ms | 16.7–16.8ms | 4 → 1 |
| 5000 根 K 线，滚轮缩放 | 50.1ms | 16.7–16.8ms | 4 → 1 |
| 5000 根 K 线 + 80 条线，滚轮缩放 | 66.7ms | 16.7ms | 4 → 1 |

5000 根、无标注的浅色主图滚轮测试中，图层重绘累计耗时从约 465ms 降至 34ms；未操作分屏的重绘次数从 141 次降到 0。原生 K 线继续跟随输入，未通过降低刷新频率或隐藏标注获得结果。

## 第二轮：完整桌面拖动停顿（2026-09-19）

用户反馈上一轮后仍会拖动一段时间才跳动。本轮将完整 renderer、全局 DOM 观察器和后台界面更新纳入验证；上一轮独立图表的帧率不能代替完整客户端的跟手性验收。

完整界面 CPU 采样复现 P95 183.3ms、最大帧间隔 233.3ms。主要耗时是时间/价格标签写入后立即读取 DOM 尺寸，以及极值标记反复写文本、量尺寸、再写文本。另一个独立问题是后台 `scheduleRender` 会移除再挂回整个图表容器；持续成交的双图测试中因此出现约 177–183ms 长任务。

本轮修改：

- 价格标签、倒计时、VPVR 和绘图表面改用图表已有尺寸；极值标签用 CSS 按真实字宽对齐到影线，时间标签使用随字号变化的宽度和 CSS 边界约束，去掉拖动路径上的同步文字测量。
- 主图及分屏视口隔离布局与绘制范围，避免标签更新扩大到整个桌面；保留明暗主题变量，极值标签只在本价格窗格内定位。
- 新增 `trading-chart-interaction.ts`，让后台整页刷新合并到原生手势结束后执行。左右/上下拖动、时间轴、窗格分隔线与连续滚轮均覆盖；释放、取消、失焦、销毁都会解除。行情事件仍然接收和绘制。
- 未显示 TD 标记时不挂载空 marker primitive；该原生插件即使没有标记也会在平移时读取、转换整个历史数组。真实 TD 开启/关闭在两图两主题中验证，关闭后全历史 `series.data()` 读取为 0。
- 复用数字格式化器，跳过相同图例文字和工具栏可访问性属性的重复写入；普通实时 K 线仅转换最后一根，HLC 保留前收盘依赖，Heikin-Ashi 和趋势染色仍保留历史依赖。

验证结果：

- 专项单测 40/40。新增覆盖后台刷新等待/恢复与合并、手势中断后的释放、绘图与极值标签禁止同步 DOM 测量。
- 扩大回归 162 项，158 通过；4 项失败与上一轮相同（收藏栏、分屏分析、mention token、旧加号菜单源码断言）。没有新增失败。
- `trading-chart-shell-performance-qa.cjs`：完整桌面、隔离 profile、合成 REST、20Hz 成交输入，双图、明暗主题、500–1500 根历史、横向/斜向拖动/滚轮，共 12 个场景。最后一次 P95 均为 16.7–16.8ms，最大帧间隔 33.5ms，无 >50ms 主线程长任务。鼠标松开前即有持续实际 canvas 绘制；横向及斜向价格位移与鼠标一致。较早压力复测有过 33.4ms P95 和单次 52ms 长任务，不能将最后一次测量当作所有机器与负载的帧率保证。
- 同脚本验证 8 组 TD 生命周期、10 个明暗/大字号标签边界，保留截图。与独立图表测试分开记录，不将 5000 根数据与完整桌面 20Hz 场景混为一项。
- 原 `trading-chart-performance-qa.cjs shell-final` 的 24 个场景全部通过，含 5000 根 K 线、80 条绘图、主图/分屏及明暗主题，P95 为 16.7–16.8ms；4 组 VPVR、订单与标注坐标检查通过。
- 连续 +/- 回归仍通过：36 组裁切恢复、24 组缩放边界、1444 次原生点击。
- 类型检查、194 modules 构建、差异检查通过。

证据：`.cache/chart-shell-before.json`（完整界面初始 CPU 采样）、`.cache/chart-shell-performance/report.json` 与明暗截图、`.cache/chart-performance/shell-final.json`、`.cache/chart-shell-regression.log`、`.cache/chart-zoom-regression/`。未修改版本或发布安装包。
