# 统一颜色选择器（2026-10-19）

用户要求 Windows 与安卓所有现有颜色入口采用参考图 1、3、4：丰富色板、添加自定义颜色与不透明度。

Windows 共用 `color-picker.ts` / `color-picker.css`。覆盖绘图浮动工具栏的线条、文字、文字背景，绘图属性中的线条与文字，图表设置中的涨跌、网格、十字线、背景，以及全部指标序列颜色。色板为 10 列、80 个预设；“＋”打开饱和度／明度平面、竖向色相、HEX 输入与增加按钮。自定义色保存至本机 `haolo.custom-colors.v1`，去重且最多 30 个，各入口共享。

不透明度支持 0–100%，100% 保持 `#RRGGBB`，其他值保存为 CSS `#RRGGBBAA`。绘图属性继续使用原有确定／取消草稿；工具栏即时生效并进入原保存链路。自定义编辑返回时丢弃未增加的颜色；外部点击、Escape、锚点隐藏／移除均正确关闭弹窗。支持亮暗主题、简英繁、键盘和窗口边缘定位。

验证：

- TypeScript 类型检查、生产构建通过（仅已有大体积 chunk 提示）。
- 相关 Node 单元测试 93 项通过。

- 绘图样式回归通过 2 个主题、29 类图形、98 个工具栏关闭／恢复案例和颜色／线宽／线型保存恢复。
