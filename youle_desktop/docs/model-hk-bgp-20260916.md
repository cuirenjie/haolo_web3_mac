# Windows 模型接口网络策略

2026-09-27 用户确认模型专用 GA 已取消。客户端不再尝试连接已撤销的模型 GA，也不再向模型策略接口发送专用能力头；国内直连模型请求统一使用普通东京源站。

## 新规则

- 每个请求先按原 URL 判断系统代理/PAC。有代理时经代理连接普通东京 `8.216.43.79`；代理失败不绕过。
- 无代理时，所有 `haolo.pro` 模型接口（Responses、聊天、模型目录、媒体和 relay）固定连接普通东京 `8.216.43.79`，不做地区探测，也不再选择香港模型 GA。
- 不发送 `x-haolo-network-capability`。已撤销的模型 GA `47.57.243.152 / 47.75.126.250` 与行情/账户入口 `47.76.124.53 / 47.238.144.244` 均不得用于模型请求。
- 公共 DNS、逻辑 URL、SNI、证书与凭证不变。已开始的付费流保持原连接；新请求重新判断，不因网络切换重复提交。
- 账号、业务、邀请保持普通新加坡，行情保留现有国内 DIRECT 分流及 5 秒活动连接检查。浏览器网关管理后台、第三方 SDK 不属于本轮覆盖范围。

## 覆盖入口

1. Codex Responses HTTP/SSE/WebSocket 和 DeepSeek relay。
2. Provider 普通/流式聊天、模型目录、Gemini 原生视频理解、豆包视频输入上传。
3. App Server 子进程 SDK/MCP、图片工具的 Python/curl 请求。
4. 主进程启动的视频生成和恢复：每次子进程运行期间建立临时本机 relay，结束或异常后关闭。媒体提交、状态轮询和 `haolo.pro` 结果下载逐请求进入统一网络传输；外部 CDN URL 保留原路由。

本机地址只进入进程环境或发送阶段，不写回用户认证文件和媒体任务持久记录。模型使用普通东京源站的现有带宽，模型流量并非免费。
