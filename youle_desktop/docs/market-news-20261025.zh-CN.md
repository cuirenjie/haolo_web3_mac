# K线与快讯页面切换

Windows 规范仓库的工具栏顶部增加圆形K线图标及 K线／快讯／浏览器菜单，绘图栏下移46px。切换快讯覆盖主画布，保留原图表、画线和周期；返回恢复原图表实例。浏览器显示“正在开发中，还未上线”。关闭绘图工具后页面入口仍保留。

快讯通过主进程认证 API `/api/market-data/news` 获取 AiCoin 真实数据。北京时间日期筛选、排他游标分页、每分钟首屏刷新、故障重试及延迟提示均已接入。标题和正文作为上游纯文本展示，跳过产品字典的局部词语替换，避免新闻内容被错误翻译。界面包含简中、繁中、英文、韩文及深浅主题。

点击交易对按交易所和现货／合约优先匹配现有行情，其他平台优先匹配同币对的币安行情。未接入的币对明确提示暂未提供行情，不跳到无关交易对。点击利好／利空设置该账号的唯一投票，重复点选取消；UI 等待后端结果，并隔离刷新和投票响应竞态。上游票数与 HaoLo 账号投票合并，新增投票不写入 AiCoin 的用户系统。

分享弹窗生成包含完整标题、正文、日期、来源及原文二维码的 PNG，打开时复制图片；支持再次复制、保存文件、复制链接，以及打开 X／Telegram 的预填分享页面。群聊按钮复制图片后由用户自行粘贴，不自动发消息。按用户补充要求，页面、来源标签、分享图、分享链接及二维码统一使用 Haolo 品牌；分享链接指向 Haolo 的公开只读快讯详情页。上游供应商标识在展示层统一转换，原始缓存仍保留供应商内容。

验收：真实上游最新／下一页／昨日／英文各30条与详情请求通过；2项客户端API测试、4项后端单元测试、3项独立PostgreSQL集成测试及2项迁移控制器测试通过。隐藏 Electron 以真实上游内容和隔离交互适配器验证导航、投票、分享、日历、分页、四语双主题、失败状态和生命周期，22张截图位于 `youle_desktop/output/flash-news-20261025/`。原图表与 canvas 引用不变。类型检查通过，Vite 构建单独记录。
