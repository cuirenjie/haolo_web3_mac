- 总资产卡片改为左侧资产摘要、右侧收益曲线，适当增加高度并统一卡片间距；内容区不足 740 CSS px 时上下排列。加载骨架使用相同布局。
- 沿用移动端的收益率 / 收益额胶囊按钮、文字加小三角周期选择。默认收益额与 7 日，支持今日、7/30/90/180/365 日。移除曲线左上角的总收益金额，保留曲线极值与末端标签。

- 收益额和收益率按零轴分色，同一条平滑曲线可同时包含正值绿色线／绿色渐变和负值红色线／红色渐变。两侧裁切同一路径，零点连续；极值与末端标签按自身正负着色，单色／零值／断点保持原始数据语义，不再使用最终总收益决定全图颜色。Android／iOS 共享 Flutter 绘制器同步修改。
