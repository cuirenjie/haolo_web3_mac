# K 线画布交互优化（M1-314）

日期：2026-09-19。范围：Windows 桌面客户端本地源码和验证。

后续规则更新：用户要求完全按 TradingView 操作习惯统一画布。本文记录 M1-314 历史实现，其中 Shift 框选、Ctrl 反转锚点及非线性框选降级已经由 [M1-315 操作契约](tradingview-chart-interactions-20260919.zh-CN.md) 替代；当前操作请以上述新文档为准。

## 视频反馈与实现

用户提供的一分钟视频在 0–18 秒演示好咯需要反复滚轮缩放、局部位置无法拖动；22–39 秒对比币安的自由移动，并提出框选局部放大；44–60 秒强调高点到达顶部后无法把走势向下拖。

主图原先通过 PointerEvent 自行修改时间范围，只允许水平移动，同时关闭了原生价格轴拖动和双击复位；视口变化和行情刷新又会强制计算可见 K 线价格范围。此次移除这套强制锁定，主图与辅助分屏共用原生图表交互与独立的 `TradingChartNavigation` 协调模块。

| 操作 | 结果 |
|---|---|
| 光标模式按住左键拖动画布 | 可上下、左右、斜向移动；超过 4px 才进入手动范围，单击不会切换缩放模式 |
| 滚轮 | 保留现有鼠标位置/右侧锚定和 Ctrl 反转；手动价格范围保持 |
| 拖动右侧价格轴 | 在线性、对数模式调整纵向比例 |
| 双击右侧价格轴 | 恢复当前可见行情的纵轴自动适配 |
| 光标模式 Shift + 拖动 | 线性坐标同时放大选区的时间和价格范围；支持反向框选和边缘夹限 |
| 对数/百分比模式框选 | 放大选中的时间窗口，纵轴交给原生自动适配，避免误用内部非线性坐标 |
| Escape、取消指针、失焦、滚轮、切换行情 | 放弃未完成选区，避免旧坐标作用于新视图 |

行情刷新、历史回补及明暗主题切换保留手动范围。坐标模式仅在确实变化时重新应用，避免图表库重算纵轴。价格标签、极值、AI/手工标注和 VPVR 在原生布局后按动画帧合并重绘；框选不生成绘图对象，也不写入撤销栈。放大按钮补充快捷键提示及英文翻译，选择框背景和边框沿用明暗主题语义色。
