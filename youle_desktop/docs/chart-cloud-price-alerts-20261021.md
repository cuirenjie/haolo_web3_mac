# 图表价格预警接入云端

2026-10-21。用户要求十字光标的价格／时间标签对齐 TradingView 黑底白字样式，价格左侧增加圆形加号；确认后创建价格预警、显示预警卡片，到价发送一次邮件，并且不依赖用户电脑在线。

## 客户端行为

- 主图和分屏使用一致的价格标签、圆形加号、分隔线与时间标签。点击加号冻结当时显示的价格、交易对和周期；取消不创建。
- 使用新的 `tradingAlertsCreateCloudPriceAlert` 桥接入口。旧主进程未重启时明确要求重新加载，不调用旧本地创建入口。
- 对 Binance 现货／永续创建服务端价格规则，目标高于或等于参考价格使用 `gte`，低于参考价使用 `lte`，即时行情触发。显示精度与确认价格保持一致。
- 云端能力检查 → 创建草稿 → 用户确认对应的规则版本／哈希 → 从服务端回读，全部成功才显示成功。重试保留幂等键；切换账户或服务地址时拒绝跨账户结果。没有本地运行或本地邮件回退。
- 预警页从云端加载对应卡片，标注「云端监控」，支持查看图表、暂停、恢复和删除，动作携带服务端版本。页面可见时刷新状态；此刷新只更新卡片，不负责监控行情。
- 简体中文、英文、繁体中文和浅／深色均覆盖。删除「请保持 Haolo 运行并联网」提示。
