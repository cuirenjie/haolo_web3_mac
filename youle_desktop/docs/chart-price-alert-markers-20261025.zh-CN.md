# 图表价格预警标记与拖动

2026-10-25，Windows 客户端源码变更，未发布安装包。

- 主图和分屏读取同一份云端价格预警快照，按完整市场标识（交易所、现货／永续、交易对）显示有效预警；切换周期仍显示同一交易对的价格预警。已暂停、完成或删除的预警不显示为有效预警线。
- 点击价格标签的加号并确认创建后，目标价格处显示水平虚线和右向三角。悬浮显示交易对、触发条件和精确价格，右侧提供删除按钮，鼠标为上下拖动箭头。
- 删除先显示确认弹窗；取消不修改，确认调用带版本号的云端删除并回读，验证成功后移除标记。
- 拖动时隐藏说明框，不平移图表；松开显示新价格确认弹窗。取消、Escape 或指针取消保留原预警，确认后新建预警并自动删除原预警。新预警沿用原周期，触发方向根据确认时冻结的参考价格确定。
- 替换在主进程中固定同一账号，先确认新预警已保存，再删除原预警并核对结果。创建失败不删除原预警；删除失败明确提示替换尚未完成，重试沿用相同幂等键，不重复创建。跨账号操作、跨市场替换和过期版本被拒绝。
- 各图表共用云端快照轮询，每 15 秒更新状态；创建、删除或外部快照事件立即更新。图表销毁后释放订阅和轮询。缩放、移动、实时价格刷新和分屏重排通过既有图表几何更新同步标记，无常驻动画循环。
- 客服知识目录同步功能说明，动作协议仍为空，未新增客服代创建或删除预警权限。

验证：价格预警、图表交互、导航、预警 UI 四组回归合计 112 项通过（价格预警 15 项），类型检查及渲染层 Vite 生产构建通过。构建产物位于 `.cache/price-alert-markers-build/`，保留现有大包体积提示，不涉及安装包或 EV 签名。原有 `scripts/trading-price-alert-qa.cjs` 的主图／分屏与浅／深色四组合通过。新增 `scripts/trading-price-alert-markers-qa.cjs` 在真实 Electron 图表上使用原生鼠标输入，覆盖主图／分屏、浅／深色、四语言删除弹窗及关闭、拖动取消及替换、缩放对齐、分屏实时行情更新、市场切换、暂停状态、删除失败及重试。云端 API 使用隔离测试替身，没有创建生产预警或发送真实邮件。截图与报告位于 `.cache/price-alert-markers-qa/`。
