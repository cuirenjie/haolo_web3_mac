# Haolo Chrome 威胁模型

## 保护目标

- 用户已登录网站中的账号、消息、业务数据和操作权限。
- Chrome 历史、下载、书签、标签页、剪贴板和本地上传文件。
- Haolo/Codex 会话身份、任务边界、授权和审计记录。
- Native Host、Desktop Broker 与扩展更新链的完整性。

## 信任边界

- 网页、iframe、选中文本、字幕和下载内容全部不受信任。
- 模型与 MCP 可以提出请求，但不能决定权限。
- Renderer 只展示状态与收集用户决定，不持有长期秘密或执行浏览器操作。
- Electron Main/Desktop Broker 和签名 Native Host 是本机可信边界。
- Chrome Web Store 签名扩展 ID 与 Native Host `allowed_origins` 共同建立扩展身份。

## 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 网页提示注入要求忽略目标、泄露历史或扩大权限 | 来源标签、系统指令隔离、页面不能修改 Grant、敏感工具单次审批 |
| 恶意扩展调用 Native Host | 正式扩展 ID allowlist、协议版本、短期会话握手 |
| 其他本机用户连接 Broker | 当前用户 Named Pipe ACL、随机 nonce、无全局 TCP 监听 |
| 模型切换到错误标签页或站点 | Grant 绑定 profile/tab/origin，执行前再次校验实际页面 |
| 点击后重定向到新域并继续操作 | 每次动作重新读取当前 URL，跨域重新授权 |
| selector 漂移导致点击错误元素 | 语义/可访问性/截图多证据定位，执行前目标摘要，执行后验证 |
| 超时重试导致重复发送或付款 | 两阶段 prepare/commit、一次性 token、幂等 operation ID |
| 读取密码、支付字段或 OTP | 敏感控件识别并从快照、日志和工具结果中删除 |
| 上传未授权本地文件 | 仅 Artifact ID，Broker 校验任务授权和规范化真实路径 |
| 历史被长期授权或批量外传 | 单次审批、结果数量/字段上限、禁止持久 allow |
| 扩展或 Host 版本漂移 | 协议协商、不兼容时只读降级或禁用、健康检查和修复 |
| Haolo 退出后扩展继续操作 | 心跳租约，Broker 断开立即停止动作 |
| 用户接管时 Agent 继续输入 | 接管检测、取消 Grant、下一动作前检查租约 |
| 日志泄露 | 递归键名脱敏、正文默认不落盘、限制诊断包内容 |

## 默认拒绝

- UAC、操作系统安全界面、Chrome 密码管理器和 DevTools。
- 密码、二次验证码、支付卡、私钥和会话令牌读取。
- 更改账号安全、权限、恢复方式或企业管理策略。
- 无明确目标的批量发送、批量删除、批量下载或全历史读取。

## 安全退出

出现目标不确定、页面身份变化、权限过期、Host 重启、协议不兼容、用户接管或结果无法验证时，任务必须暂停或失败，不得用更宽权限自动恢复。
