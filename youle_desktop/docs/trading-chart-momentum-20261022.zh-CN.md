# K 线低延迟拖动与惯性滑行（M1-434）

日期：2026-10-22。仓库：`D:/haolo_windows_web3`，分支：`dev`。

## 交互与实现

- 鼠标按住拖动继续直接响应输入，不给跟手阶段增加缓动。修正 Lightweight Charts 从前两次移动才建立拖动原点的问题，从按下位置开始计算；原生横纵轴重算在同一次输入内合并。
- 松手后使用最近约 100ms 的有效鼠标采样计算二维速度，按真实经过时间指数减速。常数 280ms，速度／总位移受视口大小限制；60/120/144/240Hz 的轨迹一致。缓慢微调、点击、松手前停顿和触控手势不触发鼠标惯性。
- 在原生时间轴／价格轴上移动，不平移截图或整个 DOM。主图、指标与绘图继续使用同一真实坐标；线性、对数、百分比、反转轴和分屏保持独立。锁定纵轴时只沿水平方向滑行。
- 再次按下、滚轮、Esc、切换上下文、失焦、隐藏或销毁立即终止；到达原生时间边界不反弹。超过 120ms 的异常帧间隔终止惯性，避免后台恢复时大幅跳动。系统减少动态效果开启时不启动惯性。
- 惯性结束前继续持有图表交互保护，后台桌面更新不能在滑行途中拆卸图表。新拖动／滚轮接管时不提前释放保护。
- 横向滚轮与 Shift+滚轮按帧累加输入，使用同步原生偏移，避免同一帧的多次异步范围设置互相覆盖；普通滚轮继续保持现有缩放契约。
- 密集手工画线的主要重压瓶颈是隐藏“添加文字”提示仍给每条线启用全画布 SVG 遮罩。改成仅提示显示时启用相同遮罩；已有正文的中间留白始终保留。悬停、选中、编辑、捕获及主题行为经过复验。

原生适配仍通过固定上游 SHA-256 和唯一替换点校验，未修改 `node_modules` 或升级依赖。
