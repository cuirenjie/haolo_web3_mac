# HaoLo Windows 0.1.178 更新说明（待审核）

日期：2026-10-21。状态：待用户审核；本任务仅提交远端 `dev`、构建 Windows x64 EV 签名安装包与整理说明，不上传生产更新系统。

## 面向用户的更新说明

### 交易分析

- 优化单个纯 `@策略` 或 `@指标` 请求：直接进入云端分析，减少本地编排和重复往返，保留完整报告、原有模型选择与交易计划。带补充文字、多个引用及附件的任务继续使用原流程。
- 分析正文逐段展示，与 K 线逐笔绘制并行进行；计划卡在正文展示完成后出现。修复重复完成提示、“已处理”分组重复以及任务完成后侧栏仍转圈的问题。
- 改善模型异常和长时间无有效进展时的备用模型恢复；修复多策略分析期间图表上下文变化引发的重复重开、反复截图和长时间无法结束。
- 兼容完整三档止盈回执，明确显示无法继续的分析错误，并保留同轮已经完成的结果。

### 图表与计划

- 支持同轮多份 AI 绘图顺序切换，并记住选中的绘制结果；会话、市场、周期及分屏分别保存。
- 修复手工绘图文字输入后消失、点击工具栏丢失焦点和内容的问题，改善持续数据刷新时按钮点击响应。
- K 线画布增加实时时钟，统一价格和时间标签样式。
- 计划卡增加整卡点击菜单，可加入或查看计划、跳转原始 K 线绘图、创建桌面便利贴，以及预览、复制或保存计划分享图片。
- 修复历史会话中计划卡片缺失，以及历史报告和绘图恢复问题。

### 价格预警与账户

- 图表价格旁新增“+”入口，确认后创建云端价格预警；支持查看、暂停、恢复和删除。到价后向账号绑定邮箱发送一次邮件，云端监控不依赖电脑保持运行。
- 优化账户摘要、委托、历史和收益日历的并发读取、刷新与失败重试，分别处理限流等待，减少重复请求及跨页面错误影响。
- 历史收益率按“已实现盈亏 ÷ 已平仓成交本金”显示；改善收益日历卡片布局和明细加载体验。

### 图片、视频与外部渠道

- 图片生成与编辑接入官方 GPT Image 2 路径，沿用 HaoLo 登录与用量记录；改善超时后的结果恢复，避免不确定状态下自动重复提交。
- 视频使用实时可用模型目录，保留用户选定参数；已有任务继续查询原任务，不在状态不明确时自动重复生成。
- 优化微信、飞书、Telegram 交易页面顶栏，并修复 K 线截图及计划卡图片交付、周期识别与卡片排版问题。
- 补齐新增功能的英文文案，保持简体中文、繁体中文与英文界面支持。

## 审核时需知

1. 纯 @ 分析的优化已通过隔离回归及界面验收，未测量本安装包在真实模型上的端到端提速比例；“逐段展示”是完整校验报告的渐进呈现，不表示模型 token 直通。
2. 价格预警依赖云端能力检查。此前任务已记录 API 与独立 Worker 上线，但本轮没有部署或更改任何后端；正式发布前仍须刷新线上状态并验证兼容性。
3. 账户今日盈亏、429 额度分配及历史同步的部分服务端修复，前序任务按用户要求暂未上线。本包包含客户端改进，不能承诺仅升级安装包即可解决全部服务端异常。
4. 指标附带裸 K 综合分析与交易计划的增强仍需要配套后端发布。私有策略算法不进入客户端安装包；客户端源码仓库中的对应离线算法与测试仅随源码提交，不作为本包已上线功能宣传。
5. 微信、飞书和 Telegram 的交付改动有隔离测试证据；本轮不代用户实发消息、不创建真实预警／交易计划或下单。
