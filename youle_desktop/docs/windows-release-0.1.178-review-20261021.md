# HaoLo Windows 0.1.178 更新说明

日期：2026-10-21。状态：用户已审核通过，现已正式发布；按要求删除模型相关表述，使用本次已验证的 Windows x64 EV 签名包，保持包内代码及版本不变。

## 面向用户的更新说明

### 交易分析

- 优化单个纯 `@策略` 或 `@指标` 请求：直接进入云端分析，减少本地编排和重复往返，保留完整报告与交易计划。带补充文字、多个引用及附件的任务继续使用原流程。
- 分析正文逐段展示，与 K 线逐笔绘制并行进行；计划卡在正文展示完成后出现。修复重复完成提示、“已处理”分组重复以及任务完成后侧栏仍转圈的问题。
- 修复多策略分析期间图表上下文变化引发的重复重开、反复截图和长时间无法结束。
- 兼容完整三档止盈回执，明确显示无法继续的分析错误，并保留同轮已经完成的结果。

### 图表与计划

- 支持同轮多份 AI 绘图顺序切换，并记住选中的绘制结果；会话、市场、周期及分屏分别保存。
- 修复手工绘图文字输入后消失、点击工具栏丢失焦点和内容的问题，改善持续数据刷新时按钮点击响应。
- K 线画布增加实时时钟，统一价格和时间标签样式。
- 计划卡增加整卡点击菜单，可加入或查看计划、跳转原始 K 线绘图、创建桌面便利贴，以及预览、复制或保存计划分享图片。
- 修复历史会话中计划卡片缺失，以及历史报告和绘图恢复问题。

### 价格预警与账户

- 图表价格旁新增“+”入口，确认后创建云端价格预警；支持查看、暂停、恢复和删除。到价后向账号绑定邮箱发送一次邮件，云端监控不依赖电脑保持运行。
- 优化账户摘要、委托、历史和收益日历的并发读取、刷新与失败重试，分别处理限流等待，减少重复请求及跨页面错误影响。
- 历史收益率按“已实现盈亏 ÷ 已平仓成交本金”显示；改善收益日历卡片布局和明细加载体验。

### 图片、视频与外部渠道

- 图片生成与编辑沿用 HaoLo 登录与用量记录；改善超时后的结果恢复，避免不确定状态下自动重复提交。
- 视频保留用户选定参数；已有任务继续查询原任务，不在状态不明确时自动重复生成。
- 优化微信、飞书、Telegram 交易页面顶栏，并修复 K 线截图及计划卡图片交付、周期识别与卡片排版问题。
- 补齐新增功能的英文文案，保持简体中文、繁体中文与英文界面支持。
