# Windows 聊天计划卡菜单（PLAN-MENU-20261021）

2026-10-21 完成源码与隔离验收。参考移动仓库 `apps/mobile/lib/features/plans/execution_plan_card.dart`、`plan_share_poster.dart` 和 `data/live/invitation_share.dart`。

- 聊天卡右上角显示浅灰右箭头；卡片内容及边缘可点击，Enter／空格可打开菜单，Escape／点击遮罩关闭，方向键可选择选项。
- 未加入时显示“加入计划”，保存后留在聊天并沿用已有自动提醒流程；已加入或过期时显示“查看计划”。已有计划打开对应状态列表并定位原卡，过期未保存计划打开只读详情。
- “跳转K线画线”绑定原消息、原市场与原分析周期，加载后选中冻结绘制并调整视野；等待期间切换会话／账号则取消，不使用当前图表周期替代计划周期。
- “便利贴”复用独立桌面窗口，保持卡片字号、便利贴字号和多张卡操作隔离。
- “分享计划”生成图片预览，提供复制 PNG、原生保存对话框。公开字段仅含交易对、市场、周期、方向、策略、入场、止损、止盈、盈亏比与有效期；排除账户金额、持仓、盈亏和原始报告。
- 邀请二维码复用移动端 `/api/referrals/me/links` 与 `/api/referrals/public/resolve` 契约，每次导出重新核验归属和有效性。未配置时提供既有邀请中心入口，失败后禁用导出并隐藏旧预览。未创建邀请链接或向其他人发送消息。
- 三语与双主题；菜单执行前复核账号、计划版本、保存状态和忙碌状态；跨过到期时间的“加入”转为查看，重复绑定不重复注册事件。

主要模块：`execution-plan-menu.ts/.css`、`execution-plan-share.ts`、主进程 `execution-plan-share.mjs`；主入口只装配卡片事件、原生 IPC 和现有计划／图表能力。
