# M1-462 右侧三档止盈区间与缺档随机补齐

状态：后端源码与隔离验证已完成，未提交或生产部署。

用户最终要求新云端右侧计划三档净盈亏比依次为 `1:0.3–1:0.5`、`1:0.6–1:0.8`、`1:0.9–1:1.3`，计入既有费用。优先保留符合区间的原结构价；缺失档位在对应区间的合法价格刻度中随机补齐，允许超出原最远结构目标，不再因结构目标不足取消计划，不压缩档位。该要求覆盖此前“只筛结构、缺档等待”的决定。账户、精度及个人硬风控仍需通过。
