# K 线拖动与手工画线流畅度优化

日期：2026-10-18。固定工作目录与 Git 根目录均为 `C:\Users\潘艳芳\Documents\ChatGPT\haolo_windows_web3`。

## 修改

- 修复非磁吸画线仍跳柱的问题：Lightweight Charts 5.1 的 `coordinateToLogical` 返回整数，`logicalToCoordinate` 也只接收整数。现在使用相邻整数柱的投影反解连续逻辑坐标，支持两柱之间、历史空隙及未来区域；开启磁吸时仍吸附最近 K 线的 OHLC。
- 普通端点/整图拖动在一帧内合并到最新输入；笔刷保留浏览器提供的全部合并采样，松开时补齐最后坐标。取消、丢失捕获、失焦、销毁均清理待绘制帧，端点取消恢复原几何。
- 新增手工 SVG 保留图层，按 ID 保留对象和命中节点。视口变化时，结构相同的 SVG 直接更新变化属性；结构、样式、文本变化使用 DOM 对照更新。保留排序、删除、实体解码和不同工具的命中范围。
- 画线预览/端点拖动只重算正在操作的一个图形，其他手工图形、AI 标注和订单背景保持原状态。视口、行情、主题等正常刷新仍完整更新所需图层。
- 工具栏状态按真实 DOM 元素缓存，尺寸由 ResizeObserver 更新；避免每帧重复写按钮状态、测量工具栏及设置相同 SVG 尺寸。
- 手工拖动期间沿用现有桌面刷新保护，避免后台界面刷新移除图表容器。行情仍继续接收和绘制。
- 主图当前价和十字光标价格文字未变化时不重建文本节点，减少完整桌面 MutationObserver 和布局工作。

本轮不改变 AI 分析协议、Drawing Gateway、订单/交易行为或绘图存储格式。

- 主图及分屏 MA / EMA / BOLL / BBI、成交量均线保留每根已完成 K 线的计算状态。一次输入比较定位最早变化；实时末根从其前一根状态重算，历史修正和补历史重算后续部分。保留主图滚动求和与分屏窗口求和的原有差异，逐点对照原始公式，不使用近似指标或缩短历史。
