# M1-468 威科夫完整形态取景

2026-10-26：源码与隔离验收完成。仅调整 Windows 威科夫绘图定位，未重启用户客户端、提交、推送、打包或发布。

## 问题与修复

用户截图显示绘图完成后只剩最近的 D／E 阶段，早期区间和阶段在画布左侧被裁掉。M1-467 的通用近期结构取景同时作用于绘制前定位和绘制结束后的计划定位，按可读柱宽限制可见数量；较长威科夫形态因此被截断。

`trading-analysis-viewport.mjs` 增加威科夫专用分支：以已识别形态的全部时间锚点计算范围，涵盖箱体、阶段、事件和预测路径，保留左右留白，不再按通用柱数上限截掉早期阶段。计划水平线的任意起终时间不扩大范围。历史分析仍定位到历史区间，附近最新 K 线仍可纳入。形态本身的价格、时间和识别结果不改，不补造未识别的阶段。

实际图表验证发现，绘图转为本地保存模型后会保留语义颜色 Token，却不保留原生 theory。因此识别同时兼容原始 theory、策略 strategyId 和已校验的 wyckoff-* Token，确保最终定位和打开已有计划仍使用完整范围。

`trading-ai-plan-autoscale.ts` 对没有交易计划的威科夫形态也纳入可见几何的价格范围，避免预测终点超出纵轴；其他策略仍保持有计划时才参与该适配的规则。手动导航不反复触发完整定位。
