# A / L 主副图坐标隔离修复（2026-09-19）

## 问题与根因

主图切换 L 时，`chart.applyOptions({ rightPriceScale: { mode } })` 会将坐标模式广播给图表的所有窗格。成交量因此进入对数坐标，量柱高度差被压缩；MACD 等指标的原始单位也受到影响。原始行情数据没有变化。

此外，Lightweight Charts 5.1 的窗格级 `priceScale.applyOptions` 仍会更新创建新窗格时使用的默认配置。只把广播调用换成窗格调用，并不能解决新增指标或重开客户端后的模式继承问题。

原 A / L 按钮跟随上一次点击的窗格，但没有标示目标。A 是开关：自动适配开启时点击会关闭，轴范围可保持不动，这部分并非按钮失效。

## 最终行为

- 图表级配置只应用共同颜色、边框等外观；模式、自动范围及主图上下留白只应用于主图价格轴。
- 主图和分屏中新建的指标窗格明确使用正常线性坐标；模拟指标的独立窗格也明确初始化坐标，主图叠加指标继续使用主图坐标。
- A / L 显示“主图”标识，固定控制所属图表的价格轴，不随指标焦点变化。悬停和无障碍提示说明当前开关状态及点击动作。
- Alt + L / P 同样只控制所属图表的主图。指标右键菜单保留该副图的自动适配、反转坐标，不提供价格对数/百分比模式。
- 主图快捷键及 L 不再覆盖现有其他分屏的模式；全局图表设置实际变更仍同步各图主图，不覆盖指标。
- 明暗主题切换及价格模式切换保持副图手动范围、自动适配状态、坐标模式和留白。
