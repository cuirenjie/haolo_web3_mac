# 回归趋势计算与交互（2026-10-19）

## 原因与参考

旧实现将 `regression-trend` 交给普通 `renderChannel`：使用鼠标端点确定斜率，再按屏幕距离偏移上下边界，没有读取所选区间的 K 线。这会产生截图 3 中的手动画线通道。

TradingView 的回归趋势只以两个端点选择 K 线时间范围。绘制阶段的连线是辅助线；结束选点后，中轨及上下轨由数据计算，因而向下画辅助线也可以生成向上的回归通道。

参考官方资料：

- [回归趋势工具、参数与坐标](https://www.tradingview.com/support/solutions/43000518108-regression-trend-drawing-tool/)
- [回归趋势默认配置](https://www.tradingview.com/charting-library-docs/latest/api/interfaces/Charting_Library.RegressiontrendLineToolOverrides/)
- [官方 Linear Regression 计算示例](https://www.tradingview.com/pine-script-docs/v4/essential/drawings/#linear-regression)

计算实现采用官方公开 Linear Regression 示例的算法，并结合用户截图还原绘制阶段与完成阶段的切换。未取得用户截图对应的完整 OHLC 数据，未对该图的数值逐根比对。

## 计算

- 两端吸附最近的实际 K 线，包含首尾；反向选择不改变拟合结果。
- 默认价格源为 close，支持 open/high/low/hl2/hlc3/ohlc4。
- 以 K 线序号 `x = 0 ... n-1` 作自变量，使用普通最小二乘拟合 `a + bx`。不使用鼠标价格，也不使用时间间隔作为权重。
- 残差标准差 `σ = sqrt(Σ(yᵢ - ŷᵢ)² / (n-1))`。默认上轨 `ŷ + 2σ`，下轨 `ŷ - 2σ`，上下倍数可独立配置。
- Pearson’s R 按官方示例取价格与拟合值的相关性，因此非负；水平序列为 0。它不是带方向的价格与时间相关系数。
- 关闭某侧“使用偏差”时，参考官方计算示例改用区间最高价/最低价相对拟合线的最大偏离；显示隐藏分别由样式中的上轨/下轨开关控制。
- 少于两根有效数据时不提交；不会用任意屏幕宽度或缺失价格伪造通道。

## 交互与外观

- 第一次点击固定起点，移动鼠标只显示灰色辅助线；第二次点击后生成回归通道。也支持按住拖拽后松开完成。
- 端点只改变时间范围，竖直拖动不改变计算；整体拖动按整根 K 线平移范围，再拟合新范围。反向端点和休市时间间隔均可处理。
- 中轨为 1px 红色虚线，边界为 2px 蓝色实线，上半区蓝色、下半区红色，默认填充不透明度 30%；显示 Pearson’s R 和计算后的端点价格。
- 参数、样式和时间坐标在专用设置面板中编辑，确认后生效；取消不写入。支持右延长、独立轨道样式和显示开关。
- 存储保留时间锚点与配置，渲染时以当前 K 线重新计算。因此缩放只改变投影，区间内行情更新会改变拟合结果。
- 旧的回归趋势对象保留原时间范围并使用真实回归计算，无需重新绘制。手工指定过的公共颜色、宽度和线型继续作为覆盖值。
