# 坐标设置迁移与上下拖动锁定（2026-09-19）

## 用户要求与结果

- 移除右下角“主图 A L”控件。齿轮设置的“坐标选择”页提供自动适配价格、对数坐标；默认不勾选。百分比坐标保留为可取消的选择，与对数坐标互斥，均不勾选时使用线性坐标。
- 底部缩放、平移、重置工具条最右侧新增锁定按钮。默认解锁，可以自由拖动；锁定后恢复旧版效果：左右拖动时，纵轴持续按当前可见 K 线最高价、最低价自动适配。再次点击恢复自由拖动。
- 锁定会动态更新价格范围，不改动保存的自动适配设置或其他分屏，不影响独立副图坐标。亮暗主题采用现有颜色变量，按钮包含未选中、选中、悬停、焦点、禁用和无障碍提示。
- 设置版本升至 5。旧版 A/L 模式迁移为默认关闭，其余图表设置保留；用户在新版设置页作出的选择会保存。锁定状态属于当前图表会话，重开默认解锁。

## 实现要点

未锁定且自动适配关闭时，首次加载、重置及显式缩放仍先完整适配一次，再固定价格范围。Lightweight Charts 的时间范围写入会排队至下次绘制，冻结价格前必须让原生图表完成该次绘制，防止连续缩放时固定到旧价格范围。

经用户纠正，锁定不能仅禁止上下位移、保持原价格范围。已 fetch GitHub `origin/dev` 并对照 [2026-09-16 的历史代码 a6b9757](https://github.com/cuirenjie/haolo_windows_web3/blob/a6b975760105de9978e72968e375d3dbe8c2589d/youle_desktop/src/renderer/trading-expert-market.ts)：旧版 `updateVisiblePriceScale` 对线性主图使用 `visibleCandlesInLogicalRange` 和 `fixedPriceScaleRange`，依据可见高低点、设置中的上下留白和刻度取整重算范围；对数/百分比及分屏使用原生自动适配。本次恢复同样的计算规则，直接复用现存历史函数。

锁定期间暂时关闭原生按压平移，由导航控制器每帧最多提交一次水平位移，并在同一帧重新适配可见价格；不会触发“适配一次后冻结”的默认逻辑。解锁恢复原生鼠标/触摸平移及原有 A 设置。按键松开时提交末次水平位置；取消手势会丢弃尚未提交的位移，沿用已有 shell 渲染延后机制。

百分比坐标的基准价格会随最左侧可见 K 线变化；测试验证实际高低点像素仍在画布内，不把绝对价格位置不变当作锁定成功。
