# M1-429：Windows 单个纯引用分析快通道

2026-10-21 完成源码实现与隔离验收。对应 ADR-056，依据用户明确批准的第一阶段范围实施。

## 行为与边界

- 桌面交易会话空闲时，输入内容完整匹配一个已启用的官方 `@策略:…` 或 `@指标:…`，直接调用既有云端策略分析入口。覆盖当前 11 个策略和 6 个指标及目录别名。
- 直接使用云端完整 `report` 生成最终回答及原有计划卡；跳过根模型的意图理解、账户工具编排、分析工具往返、画线／展示工具往返和最后一轮总结，也不压缩根会话上下文。
- 保留发送时选定的模型与显式选择标志、`reasoningEffort=max`、`responseMode=full`。云端原有确定性引擎、偏好、账户风控、报告生成和回执验证继续生效；不改服务端协议和质量策略。
- 使用发送时冻结的市场、周期、可见区间及分屏上下文。请求不另传显式 symbol，避免既有运行器重新解析当前图表。保留 Drawing Gateway、绘图动画、指标叠加、计划卡和计划生命周期。
- 先保存原始用户消息，再调用分析；完整报告与 cloudReports 一起持久化。恢复日志只在保存成功后确认。保存失败保留既有重试机制，不重新分析、不自动转入根模型。
- 支持停止、防重复提交和会话替换；完成后恢复发送按钮。切换账号取消本快通道任务，并禁止旧请求发布报告。

以下请求保持原智能体流程：带其他正文（包括“解释原因”“不要画线”等）、多个 @、附件、引用消息、会话引用、预警／自定义策略待续流程、渠道／群聊、非执行模式、不支持的云端模型、自定义或禁用目录条目、无有效图表，以及正在处理或有排队请求的会话。
