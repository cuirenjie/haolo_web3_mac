# 桌面新闻通知

本地实现，未发布安装包。`youle_desktop/src/main/news-feed.mjs` 持久化游标与待处理队列；`news-windows.mjs` 使用 `main.mjs` 既有任务通知 HTML 样式，独立创建新闻窗口。保留右下角位置、深浅主题与关闭按钮，取消新闻的自动消失；点击固定官网文章网址后打开系统浏览器。标题和正文摘要均来自发布内容，不额外添加“未点击时……”等操作说明。

队列在写盘成功后才展示并推进游标；只有用户点击／关闭会删除记录。应用退出保留未读项，下次启动恢复；同时最多三条，空间不足时减少数量。后台进程模式不展示新闻，主进程启动后每 30 秒读取最近 30 天的发布事件。HTTP 错误和非法返回不推进游标。

验证：news-feed/news-windows 共 3 项测试通过；typecheck 与 Vite 构建通过。`youle_desktop/scripts/verify-news-native.mjs` 使用真实 Electron 窗口、合成标题和拦截的浏览器打开动作，证实超过 8 秒仍显示、点击网址、关闭、深浅主题。`--preview-only` 在隐藏窗口生成审阅截图，避免影响用户操作；输出在根目录 `output/news-20261025/`。图中没有发布真实新闻。

macOS 共用窗口实现，但未做 macOS 原生验收。需配套官网、业务后端和发布选项上线，再按桌面发布流程构建签名安装包；本次没有升版本、打正式安装包或发布更新。客服知识已生成候选，候选不等于生产启用。
