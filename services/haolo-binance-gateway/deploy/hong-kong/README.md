# 香港公共行情候选节点（4 核 16 GB）

**此处保留早期 market-only/GA 候选方案，未作为现网部署。** 2026-09-19 已另行迁移官网、邀请中心、公共行情和私有 CONNECT 到香港普通公网；现行布局与发布步骤见 [香港生产流程](../../docs/hong-kong-production.zh-CN.md)。不要对现网执行此目录的 Compose，也不要按下文旧方案改回 GA/新加坡；下文仅供重新评审独立扩容方案时参考。

## 路由边界

- 国内直连：沿用客户端的香港普通 GA 地址；待新增仅匹配 `market.youle.pro` 的 GA SNI 转发规则，将公共行情送到香港 ECS 私网。
- 开代理、境外：沿用新加坡普通入口与现有客户端策略。
- 模型仍回东京；官网、帮助中心、账号和私有账户出口保留现状。安装包仍走 CDN。
- 移动端游客实时行情继续直连 Binance。
- 此节点直接获取 Binance 公共 REST/WS，共享上游连接并在香港广播。不能把 Binance 上游 URL 改成每客户端转发新加坡，再声称省了跨区流量。
- `market` 角色无 CONNECT 端口，不签发私有代理许可、不持有业务 JWT 签名密钥；通过原账号接口校验身份。生产模式禁止匿名。

## 准备与接入

1. 香港 ECS 安装 Docker/Compose，准备固定镜像、仅内网或本机 Redis、新的独立 metrics token。复制 `env.example` 为服务器上的 `.env`，替换镜像和 token。
2. 本配置只监听 `127.0.0.1:8787`。受控 TLS 入口转发 `market.youle.pro` 到该端口，保留 Host、WebSocket Upgrade；不要公开 Redis/metrics。证书须覆盖现有行情域名，不关闭证书验证。
3. 在香港现场验证 Binance REST、`/market/stream` 和 `/public/stream` 的可达性、延迟、限流。`/ready` 只代表缓存/服务可用，不能代替上游可达性验收。
4. POST `/api/market/v1/tickets` 和使用它的 WebSocket 必须进入同一地域的 Redis。票据是一次性，切地域须重新获取。禁止将发行票据的 HTTP 随机分给新加坡、WS 随机分给香港。
5. 在正式改 GA 前，为香港候选配置原域名的 TLS/健康检查和仅行情 SNI 规则。不得把 GA 默认组整体改到香港，否则官网和模型会错路由。保留当前新加坡终端组、配置快照和回退步骤。
6. 5% → 25% → 50% → 100% 灰度；比较真实行情内容/序列、时间戳、P95/P99、重连、CPU、事件循环、内存、出口和上游限额。香港异常时回退新加坡，客户端重新获取票据并按既有恢复流程补数据。
7. 单台香港节点不能承诺主机故障时不中断；回退新加坡还必须验证它能承受回退负载。不要删除新加坡节点。
8. 后续发版使用独立候选端口、入口切换和旧连接排空。不要对活跃节点执行 `compose down`，也不要把 Compose 的停止宽限期当作已完成长连接排空。

## 80% 的验收口径

80% 是公共行情本地处理的目标，不是全站流量、所有用户或账单必降 80%。应用计数器 `websocketMarketPayloadBytes`、`restPayloadBytes` 是压缩前字节，只用于应用分布，不能直接当 CDT 计费字节。

对同一完整时间窗比较香港/新加坡公共行情成功响应量和应用字节，再核对 GA→新加坡 CDT 实际跨区字节（排除官网、鉴权与模型变化）。应同时记录香港取上游的数据、新加坡回退比例和新增 ECS 公网费用。不得把下载 CDN 和同一段流量重复计入。

## 压缩与压测

`HAOLO_MARKET_WS_COMPRESSION_PERCENT=0` 为当前推荐值。可选 5/25/50/100；按已认证用户稳定分组，至少 1 KB 才压缩，限制 zlib 并发，禁止跨消息上下文保留。

2026-09-19 本机 1875 连接的合成回放中，0% 和 5% 均完整收到 187500 条消息且顺序无错，但 5% 的 P99 明显退化。不得据此启用生产压缩；这是功能能力，不是已验收的性能收益。[ws 官方说明](https://github.com/websockets/ws/blob/master/README.md)

复现：`node scripts/benchmark-market-fanout.mjs 1875 0` 或 `1875 5`（在网关目录）。脚本仅本机合成消息，不访问 Binance 或生产账户。它不等价于香港 4 核 16 GB 的容量验收；现场仍需 5 倍持续负载至少 2 小时、10 倍突发至少 15 分钟。
